# M10 — Trust engine (D)

**Status:** ✅ done 2026-10-22, on branch `develop`.

## What was built

`spm/core/trust.py` is pure and returns *decisions*; M13 persists them.

| Function | Behaviour |
|---|---|
| `trust_score(α, β)` | `α / (α + β)` |
| `is_high_trust(α, β)` | score ≥ 0.80 **and** evidence `α + β − 2` ≥ 10 |
| `report_weight(trust, age_h, half_life_h, location_verified)` | `trust × 0.5^(age/half_life) × (1 or 0.5)`; negative trust counts as 0 |
| `corroboration_window_h(half_life_h)` | `max(6, 0.5 × half_life)` |
| `agree` / `contradict` | `|ln(p1/p2)|` ≤ 0.05 / > 0.10. Between the two, neither applies. |
| `independent(a, b)` | different reporters, and not the same IP hash within 10 min |
| `is_corroborated(target, others, window_h, high_trust)` | `(ok, supporting_ids)`: an independent agreeing report within ±window, or high trust |
| `resolve_pending(pending, new, new_z_market, window_h)` | detailed below |
| `settle_normal(new, peers, window_h)` | detailed below |
| `verified_shop_price(obs, now, half_life_h, high_trust)` | `(verified, price, cluster_ids)`, detailed below |

### `resolve_pending`

Only pending reports independent of `new` and within the window are considered:
- **Agrees with `new`:** it becomes `SHOP_OUTLIER`, and its reporter gets +1 α.
- **Contradicts `new`, and `new` agrees with the market** (|z_market| ≤ 2): it becomes `BAD_REPORT`, and its reporter
  gets +1 β.
- **Anything else:** it's left PENDING.

### `settle_normal`

Only independent peers within the window count:
- **At least one peer agrees:** +1 α to the new report's reporter and to each agreeing peer's reporter.
- **Otherwise,** if two peers that are independent of each other agree with each other and both contradict the new
  report: +1 β to the new report's reporter.

Agreement takes precedence: a corroborated report is never penalized.

### `verified_shop_price`

- Excludes PENDING, BAD_REPORT and EXPIRED observations, and anything older than 2 half-lives.
- The cluster is every observation that agrees with the most recent one.
- It's VERIFIED if any two cluster members are independent, or any member's reporter is high-trust.
- The price is the weighted median of the cluster (`report_weight`). With all-zero weights it falls back to the plain
  median.

### Decisions

`TrustDelta(reporter_id, d_alpha, d_beta, report_id, reason)` and
`PendingResolution(report_id, new_classification, resolved_by, deltas)`.

## Deviations (also in the Decision log)

- **`settle_normal`:** agreement takes precedence, and the contradicting pair must also be independent of each other.
- **`verified_shop_price`:**
  - unscored observations count
  - the latest observation is chosen deterministically, by `(observed_at, report_id)`
  - a plain median is used if every weight is 0
  - the price is returned even when it isn't verified
- **`is_corroborated` returns the supporting ids even under high trust,** and negative trust is clamped to 0.
- **`AuthService` uses the trust prior constants.**

## Known limitations

- **Nothing calls these functions yet.** M11 (the classifier) and M13 (the scoring worker, which persists deltas and
  marks `trust_settled`) use them.
- **The "at most once" rule for reputation is up to the caller.** `settle_normal` doesn't know which peers were
  already settled; M13 must pass only unsettled peers and then mark the reports in the returned deltas.
