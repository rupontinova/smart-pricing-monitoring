# M01 — Backend skeleton

**Status:** ✅ done 2026-10-22.

## What was built

| File | Purpose |
|---|---|
| `spm/config.py` | `Settings` with every §2.6 field (`SPM_` prefix, `.env`), cached `get_settings()`. Secrets are `SecretStr`, so they never appear in reprs. `SPM_CORS_ORIGINS` is comma-separated. When `SPM_ENV=aws`, settings refuse empty or `change-me` values for `jwt_secret`, `admin_api_key` and `ip_hash_salt`. |
| `spm/logging.py` | `configure_logging(settings)`: structlog renders a pretty console in `local` and JSON elsewhere. stdlib loggers such as uvicorn go through the same renderer. Context vars `request_id` and `correlation_id` are merged into every line. Tracebacks are rendered without frame locals. |
| `spm/container.py` | `Container` dataclass (`settings, clock, ids` real; `db_engine, session_factory, redis, bus, notifier, metrics` are `None`), plus `build_container()` and `Container.close()` |
| `spm/core/clock.py` | `SystemClock` returns aware UTC. `FixedClock` supports `set()` and `advance(days/hours/minutes/seconds)`, rejects naive datetimes and converts to UTC. |
| `spm/core/errors.py` | Base `SpmError` (`code, status, title` class attributes; `detail, extra` per instance). Subclasses are added in M02. |
| `spm/adapters/ids.py` | `new_uuid7()` and `UuidV7Generator` (backed by `uuid-utils`, returns stdlib `uuid.UUID`) |
| `spm/adapters/probes.py` | `ping_postgres(url)` and `ping_redis(url)`: one-shot probes with a 2 s timeout |
| `spm/api/app.py` | `create_app(settings=None)`: lifespan builds and closes the container on `app.state.container`; adds middleware, exception handlers and the health router |
| `spm/api/middleware.py` | Pure ASGI middleware: `RequestIdMiddleware`, `ServerTimingMiddleware`, `BodySizeLimitMiddleware` (16 KB), `UnhandledErrorMiddleware` |
| `spm/api/errors.py` | `problem()` builds RFC 9457 responses with `type, title, status, code, detail?, …extra, request_id`. Handlers cover `SpmError`, `RequestValidationError` (adds an `errors` list with `loc/msg/type`) and `StarletteHTTPException`. |
| `spm/api/deps.py` | `get_container`, `get_settings_dep`, plus the `ContainerDep` and `SettingsDep` aliases |
| `spm/api/routers/health.py`, `api/schemas/health.py` | `GET /healthz` returns `{"status":"ok","version":…}`. `GET /readyz` returns `{"status":"ok","checks":{"db":…,"redis":…}}`, or a 503 `SERVICE_UNAVAILABLE` problem with the same `checks`. |
| `spm/entrypoints/cli.py` | `spm api` runs uvicorn as a factory; `--reload` is on by default in `local` and watches `src/spm` only. `worker`, `scheduler`, `migrate` and `seed` print "not implemented yet (arrives in Mxx)". |
| `spm/entrypoints/lambda_api.py` | `handler = Mangum(create_app(), lifespan="auto")` |
| `pyproject.toml` | `spm` console script |

Request middleware order, outermost first: RequestId → ServerTiming → CORS → BodySizeLimit → UnhandledError →
FastAPI exception handlers → routers.

## How to run

```bash
make api                      # http://localhost:8000/healthz, /readyz, /docs
uv --directory backend run spm --help
```

(Use `gmake` on this Mac.) `/readyz` reports `ok` for both checks while `make up` is running.

## Deviations (also in the Decision log)

- **Four codes added to the §2.5 registry:** `BAD_REQUEST` (400), `METHOD_NOT_ALLOWED` (405), `PAYLOAD_TOO_LARGE` (413)
  and `SERVICE_UNAVAILABLE` (503). Other unmapped statuses fall back to `BAD_REQUEST` for 4xx and `INTERNAL` for 5xx.
- **Base `SpmError` created now:** the M01 handler needs it. M02 adds the subclasses.
- **Catch-all error handling lives in `UnhandledErrorMiddleware`,** not in an `Exception` handler. Starlette runs
  `Exception` handlers outside every user middleware, so the 500 response would lose `X-Request-ID` and CORS headers,
  and the log line would lose its request id.
- **`/readyz` uses the URLs in settings** with one-shot connections, because the container holds no clients yet.
  An empty URL means "not configured" and reports `skipped`. M03 and M07 should switch it to the pooled engine and
  the Redis client.
- **`UuidV7Generator` lives in `spm/adapters/ids.py`:** Python 3.12's stdlib has no UUIDv7, and `uuid-utils` is a
  third-party package, so it can't go in `core`.

## Other choices worth knowing

- **Caller-supplied `X-Request-ID`** is only used if it matches `[A-Za-z0-9._:-]{1,128}`. Anything else is replaced
  with a fresh UUIDv7, which prevents log injection.
- **For HTTP requests `correlation_id` equals `request_id`,** matching §3.1.
- **Duplicate access log removed:** uvicorn's access log is silenced because `RequestIdMiddleware` already logs
  `request` with method, path, status, `duration_ms` and both ids.
- **`Container.clock` is typed `SystemClock | FixedClock`** until the `Clock` port exists. Switch it to the port in M02.

## Known limitations

- `db_engine`, `session_factory`, `redis`, `bus`, `notifier` and `metrics` on the container are `None` (typed `Any`)
  until M03, M07, M16 and M18.
- Auth, `/v1` routers and admin-key checks are not built yet (M04 and M08).
