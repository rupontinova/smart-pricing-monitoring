### Model validation (`__post_init__`)

- `GeoPoint`: latitude must be in [-90, 90] and longitude in [-180, 180]; NaN and infinity are rejected.
- `Product`: requires `half_life_h > 0` and `abs_min < abs_max`, mirroring the M03 `CHECK` constraint.
- `Reporter`: requires α > 0 and β > 0, so `trust = α / (α + β)` is always defined.

### Memory adapters

- **`SequentialIds`:** the n-th id has timestamp `epoch + n ms` and carries `n` in its random bits. The ids are valid
  UUIDv7s (version 7, RFC variant), deterministic and strictly increasing. The default epoch is 2026-01-01 UTC.
- **`MemoryRateLimiter(clock)`:** a fixed window keyed on `(scope, key, window, bucket)`, the same semantics as the
  Redis `spm:rl:{scope}:{id}:{bucket}` counter. Rejected hits still count, like `INCR`. Returns
  `(allowed, retry_after_s)`: `retry_after_s` is 0 when allowed, otherwise the seconds until the window ends
  (at least 1).

## Deviations (also in the Decision log)

- **Enum values:** members without a value in the plan use their name, e.g. `Verdict.HIGH = "HIGH"`. This matches
  the M03 DB enums and the M15 JSON.
- **`FixedClock`** stays in `core/clock.py`, where M01 put it. `adapters/memory` re-exports it.
- **Defined in full ahead of time:** `Event`, `DailyStat` (fields from M17) and `OutboxRepo` (signatures from M07).
  `SubscriptionRepo`, `AlertRepo` and `PriceCheckRepo` are empty placeholder Protocols until M15 and M16.
- **`ERROR_TYPES`** is the single list of error classes. `RateLimited(retry_after_s=…)` drives the `Retry-After`
  header.
- **`UnitOfWork`** declares `__aenter__`/`__aexit__` explicitly, so "async context manager" is part of the type.
- **Tooling:**
  - mypy strict now also covers `spm.ports`, and mypy checks `tests/` too.
  - A second import-linter contract keeps `spm.ports` free of adapters, frameworks and `spm.config`.
  - ruff allows the Greek letters α, β and σ, which are the domain notation.

## Known limitations

- No persistence yet. Repository implementations arrive in M03 and later; memory repositories are added by the
  modules that need them.
- The models don't enforce that datetimes are timezone-aware, except `FixedClock`. Adapters (M03) must store and
  return aware UTC values.
