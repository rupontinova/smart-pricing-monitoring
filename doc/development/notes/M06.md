## What was built

### `spm/core/guardrails.py` (pure)

- **`check_observed_at(observed_at, now, *, allow_backfill=False)`:** rejects observations more than 5 min in the
  future, or older than 168 h. Both boundaries are inclusive. With `allow_backfill` only the age check is skipped;
  the future check still applies.
- **`unit_error_hints(raw, product, reference) -> list[UnitHint]`** builds candidates:
  - the same quantity number in each other unit of the same dimension;
  - the same unit with the quantity scaled by ×2, ×0.5, ×12, ÷12, ×1000 and ÷1000 (rounded to 3 dp).

  It keeps a candidate only if its base quantity is in [0.05, 50] and its price is within `[abs_min, abs_max]`.
  Candidates whose prices are within 1% of each other are merged, keeping the first. The rest are ranked by
  `|ln(price / reference)|` and the top 2 returned. Example message: `"Did you mean 500 g instead of 500 kg?"`.
- **`bounds_reference(product, band_p50)`:** the band median, or `sqrt(abs_min × abs_max)` when there's no band.
- **`check_absolute_bounds(np, product, reference)`:** raises `PriceOutOfBounds` with
  `norm_price, min, max, base_unit, hints`.
- **`hints_extra(hints)`:** the JSON form, `[{message, quantity, unit, norm_price}]`.
- **`geofence(shop, fix)`:**
  - no fix: `(False, None)`;
  - otherwise `allowed = 300 + min(max(accuracy, 0), 200)`;
  - too far raises `TooFarFromShop(distance_m, allowed_m, shop_id)`, otherwise it returns `(True, d)`.
- **`is_duplicate(new, recent)`:** `|new − old| / old ≤ 0.01`.

### `spm/adapters/redis/rate_limiter.py`

`RedisRateLimiter(redis, clock).hit(scope, key, limit, window_s)`:
- **Key:** `spm:rl:{scope}:{key}:{floor(now / window)}`.
- **Pipeline:** `MULTI: INCR + EXPIRE window_s NX`, so the TTL is set on the first increment only.
- **Returns:** `(count ≤ limit, retry_after_s)`, where `retry_after_s` is the seconds left in the window, or 0 when
  the hit is allowed.

The container builds the limiter when Redis is configured.

### `spm/adapters/postgres/report_repo.py`

`PgReportRepo.find_recent_duplicate` returns `(id, norm_price)` newest first, for the same reporter, product and
shop, observed since `since`. It also filters `received_at` so Postgres can skip old partitions. `PgUnitOfWork` now
wires `uow.reports`.

### `spm/adapters/memory/reports.py`

`MemoryReportRepo` (which counts `duplicate_queries`, for the order tests) and `MemoryUnitOfWork`.

### `spm/services/guardrail_service.py`

`GuardrailService(catalog_cache, rate_limiter, uow_factory, clock, hot_cache=None).admit(...) -> Admission`.

`Admission` has `normalized, shop, location_verified, distance_m, duplicate_of`.

The checks run in this order and stop at the first failure:
1. rate limits (`scope="report"`): 30 per hour, then 100 per day
2. normalize; a `QUANTITY_OUT_OF_RANGE` error gets `hints` added
3. `observed_at`
4. the shop exists and is active
5. bounds, ranked by the cached band median when a `hot_cache` is given
6. geo-fence
7. duplicates within 6 h of `observed_at`

## Deviations (also in the Decision log)

- **`QUANTITY_OUT_OF_RANGE` carries `hints`.**
- **Hint rules:** a hint must normalize cleanly, near-identical hints are merged, and quantities are rounded to 3 dp.
- **JSON hint shape** is `{message, quantity, unit, norm_price}`, and `jsonable_encoder` handles the extras.
- **Retry and expiry:** `retry_after_s` is 0 when allowed, and the TTL uses `EXPIRE … NX`.
- **A duplicate is reported, not raised.** M08 decides the HTTP behaviour.
- **Narrow protocols** are used for the UoW and band lookup, and `hot_cache` stays optional until M12.
- **The `received_at` filter** in `find_recent_duplicate` lets Postgres skip partitions.

## Known limitations

- **The service isn't wired into the container or an endpoint yet.** That happens in M08 (`POST /v1/reports`).
- **Hints only fix quantity and unit mistakes.** A price typed 1000× too high, like 80 000 for 1 kg of onion, gets no
  hint.
- **Rate-limit buckets are fixed windows.** A reporter can send up to 2× the limit across a window boundary.
