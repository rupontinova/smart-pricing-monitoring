## How to run

```bash
cp .env.example backend/.env
make setup && make up && make check
```

On this Mac the system `make` is broken (Xcode Command Line Tools error), so use Homebrew's GNU make: `gmake ...`, or
put `/opt/homebrew/opt/make/libexec/gnubin` on `PATH` to get it as `make`.

## Local Docker runtime

This Mac uses **Colima** (Homebrew `colima`, `docker`, `docker-compose`). After a reboot, run `colima start` before
`make up`. `~/.docker/config.json` has `cliPluginsExtraDirs: ["/opt/homebrew/lib/docker/cli-plugins"]`, which makes
`docker compose` available as a subcommand.
