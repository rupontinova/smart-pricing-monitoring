# M08 — Device auth & `POST /v1/reports`

**Status:** ✅ done 2026-10-22, on branch `develop`.

## What was built

### Auth

- **`POST /v1/auth/device`** takes `{"device_id": "<uuid>"}` and returns `{token, reporter_id, expires_at}`.
  - The same device always maps to the same reporter. Concurrent first logins are safe: the insert is
    `ON CONFLICT (device_id) DO NOTHING`, followed by a re-read.
  - It's rate-limited to 20 per hour per IP hash.
- **`adapters/tokens.py` (`JwtTokens`):** HS256 tokens with claims `sub, did, iat, exp, iss="spm"` and a TTL of
  `SPM_JWT_TTL_D` days. Expiry is checked against the injected clock.
- **`api/deps.py` (`current_reporter`):** reads `Authorization: Bearer …`.
  - A missing, invalid, expired or unknown token gives a 401 with `WWW-Authenticate: Bearer`.
  - A banned reporter gives a 403.
  - `last_seen_at` is updated at most once per hour, with a single conditional UPDATE.
- **`core/privacy.py` (`hash_ip`):** `sha256(salt + ip)`. The client IP is the first `X-Forwarded-For` hop, else the
  TCP peer.

### Repositories

- **`PgReporterRepo`:** all of `ReporterRepo`, plus `touch`.
- **`PgReportRepo`:** all of `ReportRepo`. `add` writes four things in one transaction:
  1. the idempotency row, first, raising `DuplicateClientReport` on conflict
  2. `reports`, with `base_quantity` rounded to 4 dp
  3. a queued `report_assessments` row with the denormalized fields
  4. `reporters.reports_total + 1`

  `get` returns the full `Report`, including its location.
- **Read parts for the status endpoint:** `PgAssessmentRepo.get_state` and `PgBandRepo.shop_prices`.
- **Memory versions** of all of these, plus a `MemoryUnitOfWork` that carries every repo.

### `ReportService`

`submit(reporter, cmd, *, request_id, allow_backfill=False) -> SubmitResult(report, duplicate, state)`:

1. **Replay:** if `client_report_id` was seen before, return the stored report with `duplicate=True`.
2. **Guardrails:** run them. Backfill skips the age check and the rate limits. If they find a `duplicate_of`, return
   that report with `duplicate=True`.
3. **Persist:** `reports.add` plus `outbox.add([price.reported])` in one transaction. If a concurrent retry won the
   race, return its report.
4. **Publish:** `OutboxPublisher.flush`. A failure is swallowed and the sweeper retries.
5. **Metrics:** `reports_received`, `reports_duplicate`, or `reports_rejected{code}` for any `SpmError`.

`status(reporter, report_id)` returns a 404 for other reporters' reports. `verified` is true when the classification
is NORMAL, SHOP_OUTLIER or MARKET_SHIFT **and** the shop price is verified.

### `AuthService`

`register_device`, `reporter_for_device` and `authenticate`.

### Routes (`api/routers/reports.py`)

- **`POST /v1/reports`:** returns 202 for a new report, 200 for a replay or duplicate.
- **`GET /v1/reports/{id}`:** the report's scoring status.
- **`GET /v1/me`:** the reporter's own profile.
- **`POST /v1/admin/reports/backfill`:**
  - requires `X-Admin-Key`, compared in constant time (403 otherwise);
  - takes `reporter_device_id` and creates that reporter if needed;
  - is disabled on AWS unless `SPM_ALLOW_BACKFILL=true`.

### Other changes

- **Container:** adds `uow_factory` (`PgUnitOfWork`), `tokens` and `metrics` (`LogMetrics`).
- **Settings:** new `allow_backfill` setting. In `aws`, the JWT secret must be at least 32 bytes.
- **Benchmark:** `tools/bench_reports.py` sends N sequential reports and prints p50/p95/p99 from `Server-Timing`.
  Reporters rotate every 25 reports, signing in from 198.18.0.0/15 addresses.
- **Dependency:** `pyjwt`.

## How to run

```bash
make up migrate seed
make api                         # terminal 1
make worker                      # terminal 2 (logs events in local env)
TOKEN=$(curl -s -XPOST localhost:8000/v1/auth/device -H 'content-type: application/json' \
  -d '{"device_id":"6f1c2c1e-0000-4000-8000-000000000001"}' | jq -r .token)
curl -XPOST localhost:8000/v1/reports -H "authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"client_report_id":"…uuid…","product_text":"piyaz","shop_id":"shop-a","price":40,"quantity":500,"unit":"gm","observed_at":"2026-10-22T10:00:00Z"}'
uv --directory backend run python ../tools/bench_reports.py
```

## Deviations (also in the Decision log)

- **Backfill skips rate limits.**
- **The idempotency row is inserted first,** raising `DuplicateClientReport`, so concurrent retries are safe.
- **New `ReporterRepo.touch` and `Reporter.last_seen_at`.**
- **JWT expiry uses the injected clock,** and the device id must match.
- **On AWS the JWT secret must be at least 32 bytes.**
- **401s carry `WWW-Authenticate`,** and other reporters' reports are a 404.
- **Request schema rules:** `price` ≤ 2 dp, `quantity` ≤ 3 dp, and `status` reflects the real scoring state.
- **`LogMetrics` is the metrics adapter until M18.**
- **`PgAssessmentRepo` and `PgBandRepo` are partial.**

## Known limitations

- **Latency headroom is modest.** Each report opens several short transactions: auth, the replay check, the duplicate
  lookup, the insert and the outbox mark. Each checkout also pays `pool_pre_ping`'s `SELECT 1`. p99 reached 100–190 ms
  on this laptop. If M23's load tests need more headroom, merge those transactions and drop pre-ping for a
  pool-recycle policy.
- **`X-Forwarded-For` is trusted as-is.** That's right behind CloudFront and API Gateway, but a client hitting the
  API directly can spoof its IP hash (and so its auth rate-limit bucket).
- **Tokens can't be revoked;** they simply expire after 90 days. Banning a reporter blocks them at the next request.
- **`distance_to_shop_m` and `location_accuracy_m` are float32 (`real`) columns,** so 33.6 reads back as 33.599998.
